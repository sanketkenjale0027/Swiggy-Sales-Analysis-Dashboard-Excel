# Swiggy Sales Analysis Dashboard – Excel

## 📌 About the Project

This project focuses on analyzing Swiggy sales data using Microsoft Excel. The dashboard is developed to transform approximately 197K+ rows of raw data into meaningful business insights through interactive visualizations, KPIs, charts, and data analysis.

The dataset covers sales transactions from January to August, providing insights into sales performance, customer ratings, food preferences, and geographical distribution.

The dashboard helps understand sales trends, identify top-performing cities and states, and compare Veg and Non-Veg food sales.

## 📊 Dashboard Features & KPIs

- Monthly Sales Trend: Tracks sales performance from January to August.
- Daily Sales Trend: Analyzes sales across different days of the week.
- Top 5 Cities by Sales: Identifies the five highest revenue-generating cities.
- Total Sales, Rating & Orders: Provides an overview of overall business performance.
- Sales by Food Type: Compares Veg and Non-Veg sales.
- Sales by State: Visualizes geographical sales distribution across India.
- Average Customer Rating: Measures customer satisfaction.
- Average Order Value: Analyzes the average value of orders.
- Interactive Filters: Allows users to filter the dashboard by months, states, and food categories/dishes.
